# FinanceSharks — Full-Stack Implementation Plan

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 19 + Vite + TypeScript + Tailwind CSS 4 + Framer Motion (existing) |
| Backend | ASP.NET Core 10 Web API (C#) |
| Database | Supabase (PostgreSQL) via Entity Framework Core |
| Auth | JWT access tokens + refresh tokens |
| Testing | xUnit + Moq (backend), Vitest + React Testing Library (frontend) |

---

## Project Structure

```
financesharks/
├── frontend/
│   └── src/
│       ├── components/          ← UI components
│       ├── pages/               ← Page components
│       ├── context/             ← React contexts (Auth, Theme, etc.)
│       ├── hooks/               ← Custom hooks
│       ├── services/api/        ← API client + service modules
│       └── lib/                 ← Utilities, constants
├── backend/
│   └── Financesharks.Api/
│       ├── Controllers/         ← API endpoints
│       ├── Models/              ← Domain entities
│       ├── Data/                ← DbContext + migrations
│       ├── DTOs/                ← Request/response models
│       ├── Services/            ← Business logic
│       ├── Auth/                ← JWT + password hashing
│       └── Middleware/          ← Exception handling, rate limiting, security
├── .gitignore
└── plan.txt
```

## How to Run

```bash
# Terminal 1 — Backend
cd backend/Financesharks.Api
dotnet run --launch-profile http

# Terminal 2 — Frontend
cd frontend
npm run dev
```

Backend: http://localhost:5000  
Frontend: http://localhost:5173
